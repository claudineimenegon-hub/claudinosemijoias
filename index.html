🚚 Integração Melhor Envio

Configure sua conta do Melhor Envio para calcular frete em tempo real com Correios, Jadlog, Loggi e outras transportadoras.

Recomendado (mais seguro): configure o token como variável de ambiente MELHOR_ENVIO_TOKEN no painel da Netlify (Site settings → Environment variables). Assim o token nunca fica exposto no navegador e o cálculo funciona para todos os clientes.
Opcionalmente defina também MELHOR_ENVIO_CEP_ORIGEM e MELHOR_ENVIO_AMBIENTE.
O campo acima é um fallback — só é usado enquanto a variável de ambiente não estiver definida. Obtenha o token em: melhorenvio.com.br → Painel → Tokens (permissão shipping-calculate).
