# SEO e segurança

## Publicação

- O domínio canônico é `https://www.claudinosemijoias.com.br/`.
- O arquivo `robots.txt` libera o rastreamento e aponta para o sitemap.
- O arquivo `sitemap.xml` deve ser enviado ao Google Search Console.

## Headers configurados na Netlify

- `Strict-Transport-Security`
- `X-Content-Type-Options`
- `X-Frame-Options`
- `Referrer-Policy`
- `Permissions-Policy`
